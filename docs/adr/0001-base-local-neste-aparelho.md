# Base local neste aparelho

A equipe quer uma única base de Atendimentos e, no MVP, não há API. Sem servidor, isso só é verdade se a base for **este aparelho**.

Decidimos persistir tudo localmente e tratar o telefone de referência da equipe como a Base local. Vários aparelhos no MVP seriam várias bases que não se somam.

Alternativas rejeitadas: API/sync agora (sai do corte local); bases isoladas por voluntário sem deixar isso explícito (a “base da ONG” mentiria).
