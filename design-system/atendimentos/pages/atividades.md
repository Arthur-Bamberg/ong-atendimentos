# Atividades Page Overrides

> **PROJECT:** Atendimentos
> Rules here override `design-system/atendimentos/MASTER.md`.

## Page-Specific Rules

### Layout
- Phone-first list, max content width 560px.
- Catalog items are static cards (not tappable in this slice): card surface, 12px radius, 16px padding, 8dp gaps.
- Device-scope notice sits above the list as an informational card with icon + text.

### Typography
- Screen title 28px Outfit; list names 16px Work Sans, wrap (no ellipsis on Atividade names).

### Motion
- No hover lift on cards. No GSAP scroll reveal.
