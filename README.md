# Atendimentos da ONG

App local (React Native + Expo) para a equipe anotar Atendimentos neste aparelho.

## Desenvolvimento

Node 22.13+ (ver `.nvmrc`).

```sh
nvm use
npm install
npm test
npm run typecheck
npx expo start
```

A Base local fica neste aparelho. Não há servidor nem sincronização entre telefones.
